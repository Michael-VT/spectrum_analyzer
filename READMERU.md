# Анализатор спектра аудиофайлов

Программа на Rust для отображения спектральной характеристики WAV-файлов (16‑бит PCM). Строит график амплитудного спектра в децибелах, находит пики с уровнем более 50% от максимального и даёт краткое описание каждой обнаруженной частоты (основной тон, гармоники и т.п.).

## Возможности
- Чтение моно‑ и стерео‑файлов в формате 16‑бит PCM.
- Вычисление одностороннего спектра с помощью БПФ (Fast Fourier Transform).
- Отображение графика в отдельном окне (закрыть по `Esc`).
- Автоматическое обнаружение пиков спектра, превышающих 50% от максимальной амплитуды.
- Классификация пиков: основной тон, гармоники (до 5‑й, затем обобщённо), низко/средне/высокочастотные составляющие.
- Вывод подробной информации о каждом пике в консоль.

## Требования
- macOS (программа использует `minifb` для создания окна; также работает на Linux и Windows с минимальными изменениями).
- Rust и Cargo (установите с [rustup.rs](https://rustup.rs/)).
- WAV-файлы с параметрами: 16‑бит, PCM (без сжатия), любое количество каналов (будет преобразовано в моно).
